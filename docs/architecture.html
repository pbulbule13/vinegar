🏠 Overview

Vinegar is a family home AI assistant that runs on your local network. It provides voice and text chat interfaces powered by 30+ AI models, with tools for managing calendars, tasks, groceries, meals, chores, reminders, and more. All data stays local in SQLite.

🗣 Dual Voice Modes
Free mode (Web Speech API + Google TTS) and premium mode (OpenAI Realtime full-duplex). Wake word detection with passive listening.
🤖 30+ AI Models
Access Gemini 2.5, GPT-5, Llama, Qwen, and more through Euri API. Smart model selection based on query complexity.
🛠 15+ Built-in Tools
Calendar, tasks, groceries, meals, chores, reminders, activities, memories, skills. Plus custom skill creation.
🔒 Privacy First
PII redaction before LLM calls. Local SQLite database. LAN-only operation. Auth middleware with shared secret.
⚡ Token Optimized
200K daily token budget. Offline commands (0 tokens). Response caching. System prompt compressed to ~393 tokens.
📱 Cross-Platform
Desktop web app + Android APK via Capacitor 5. Server at 192.168.1.15:3000, APK builder at :8080.

🔌 API Routes (19 Endpoints)

POST /api/chat
Main text LLM endpoint. Validates input, tries offline, calls LLM middleware with full pipeline.
POST /api/chat/stream
SSE streaming endpoint. Returns progressive text chunks for real-time rendering.
POST /api/tts
Text-to-speech via Google Translate TTS. Splits text into 190-char chunks at sentence boundaries.
CRUD /api/family
Family member management. GET list, POST create/switch (with PIN), PUT update, DELETE remove.
CRUD /api/calendar
Calendar event queries by date range. Supports family member filtering.
CRUD /api/grocery
Grocery list management. Add, complete, remove items with category auto-detection.
CRUD /api/chores
Chore assignment with points/stars. Leaderboard tracking across family.
CRUD /api/meals
Meal planning by date and type (breakfast/lunch/dinner/snack).
POST /api/tools/*
Dynamic tool execution. Routes to executeTool() based on path parameter.
CRUD /api/skills
Custom skill management. Create web scrapers, API callers, data lookups.
POST /api/ai/realtime-token
Generate ephemeral OpenAI Realtime token for premium voice mode.
GET/POST /api/settings
API key management (OpenAI, Euri). Stored in cookies and database.

🔒 Security Architecture

10 P1 critical security fixes applied on 2026-02-15.

Auth Middleware

VINEGAR_AUTH_TOKEN env var. Bearer header + cookie support. All /api/* routes protected.

PII Redaction

SSN, credit card, email, phone, address redacted before LLM. Rehydrated after. Cache eviction at 500 entries.

SQL Injection Hardening

data_lookup blocks DROP/DELETE/INSERT/UNION/WITH/subqueries. Sensitive tables blocked. LIMIT required.

Prompt Injection Defense

Context sanitized to strip tool_call patterns. parseToolCall rejects responses containing memory markers.

SSRF Protection

isUrlSafe() blocks localhost, private IPs (10.x, 172.x, 192.168.x), cloud metadata (169.254.169.254).

PIN Security

bcrypt hashing. PIN required when pin_hash exists (not just when submitted). Bypass fixed.

Input Validation

Zod schemas on all API routes. Date parsing with NaN guards. Request timeouts (30s).

Token Budget

200K daily limit enforced. Per-request 8K input cap. Prevents runaway LLM costs.

⚙ Background Services

Scheduler (30s interval)

Evaluates scheduled_reminders table every 30 seconds. Fires due reminders via event bus. Handles recurring reminders (daily, weekly) by computing next fire time.

Background Worker (60s interval)

embed_memories (5 min) - Generate vector embeddings for new memories
extend_recurring_events (daily) - Create calendar events 2 weeks ahead
db_backup (daily) - VACUUM INTO backups/, keep last 7
cleanup_old_logs (daily) - Delete logs older than 30-90 days
