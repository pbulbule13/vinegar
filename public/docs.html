Overview

Vinegar is a family home AI assistant available as an Android APK and desktop server application. It runs entirely on your local home network, keeping all personal data on your own hardware.

Type
Family Home AI Assistant
Platforms
Android APK + Desktop Server
Frontend
Next.js 14, React 18, TailwindCSS
Database
SQLite (better-sqlite3), local-first
Mobile
Capacitor 5 (Android builds)
LLM Provider
Euri API (text generation)
Voice Input (STT)
Web Speech API (in-browser)
Voice Output (TTS)
Browser SpeechSynthesis (private, local)
Server Address
http://192.168.1.15:3001
Data Storage
All data stored on home server, SQLite database with 18 tables, 7 migration phases

Tools Reference

Vinegar has 26 built-in tools available for the AI to call during conversations. Each tool uses a registry pattern and is invoked via a text-based protocol. Click any tool below to expand its details.

1 save_memory Save information to long-term memory ▶

Persists information to Vinegar's long-term memory store so it can be recalled later. Use this for facts, preferences, routines, decisions, and information about people.

ArgumentTypeDescription
topicstringThe topic or subject of the memory
contentstringThe content to remember
typeenumOne of: fact, preference, routine, decision, person, conversation
importanceenumOne of: low, medium, high

Example

{
  "tool": "save_memory",
  "args": {
    "topic": "Dad's coffee preference",
    "content": "Dad likes his coffee black with no sugar",
    "type": "preference",
    "importance": "medium"
  }
}
2 recall_memory Search stored memories ▶

Searches Vinegar's memory store using a text query. Can optionally filter by memory type.

ArgumentTypeDescription
querystringSearch query to find relevant memories
typeenum?Optional filter: fact, preference, routine, decision, person, conversation

Example

  "tool": "recall_memory",
  "args": {
    "query": "coffee preference",
    "type": "preference"
  }
}

GET/POST /api/reminders Reminders. GET to list, POST to create/dismiss.
GET/POST /api/settings API key settings. GET to read, POST to save keys.
GET/POST /api/settings/tts TTS and voice settings: language, speed, pitch, voice selection.
GET/POST /api/settings/location Location settings: home address, work address, ZIP, coordinates.

Voice Features

Vinegar supports full voice interaction with a wake/sleep cycle, speech recognition, and text-to-speech output -- all running privately in the browser.

Wake / Sleep Cycle

  • Wake word: Say "Vinegar" to activate voice mode. The orb transitions from idle to listening state.
  • Sleep phrases: Say "go to sleep", "goodnight", or "sleep" to deactivate voice mode.
  • Auto-sleep: After 60 seconds of silence, Vinegar automatically returns to sleep mode.

Speech-to-Text (STT)

  • Engine: Web Speech API (runs entirely in the browser, no data sent externally)
  • Languages: English US (en-US), English India (en-IN), Hindi (hi-IN), Marathi (mr-IN)
  • Processing: Real-time transcription displayed in a floating transcript bubble

Text-to-Speech (TTS)

  • Engine: Browser SpeechSynthesis API -- fully private, no text sent to Google or any external service
  • Languages: English US, English India, Hindi, Marathi
  • Speed: Configurable from 0.8x to 2.0x (default 1.2x)
  • Pitch: Adjustable for each voice
  • Voice selection: Automatic (best match) or manual selection from available system voices

Privacy & Security

Vinegar is designed with privacy as a core principle. All data stays on your home server, and external API calls are carefully controlled.

Local-First Storage

All data is stored in a SQLite database on your home server. Nothing is uploaded to the cloud. Your family's information never leaves your network unless explicitly requested (e.g., weather lookup).

PII Redaction

Before any external API call, personally identifiable information is automatically stripped: Social Security numbers, credit card numbers, email addresses, phone numbers, and street addresses. Family names are intentionally not redacted for usability.

Private Voice Processing

Both speech-to-text and text-to-speech run entirely in the browser using Web Speech API and SpeechSynthesis. No audio or text is sent to Google, Amazon, or any external service for voice processing.

CORS & Security Headers

The server enforces CORS policies and security headers via next.config.js to prevent unauthorized cross-origin requests.

Rate Limiting

All API endpoints are rate-limited to 60 requests per minute per IP address via middleware, preventing abuse or runaway requests.

Child Safety Mode

When a child is the active user, a special safety prompt is injected into the LLM context to filter inappropriate content and ensure age-appropriate responses.

SSRF Protection

Custom skill URL fetches include SSRF (Server-Side Request Forgery) protection to prevent skills from accessing internal network resources maliciously.

Secure File Handling

All *.db files, .env.* files, backups, and logs are excluded from version control via .gitignore.

Data Flow Summary

  • Voice input is processed by Web Speech API entirely in the browser. Transcribed text is sent to the server over LAN.
  • Chat messages are sent to the Next.js server, which invokes tools as needed, then calls the Euri API for LLM responses.
  • PII filtering strips sensitive data before any external API call. Only the minimum required data is sent externally.
  • Tool results are stored in the local SQLite database. The offline-first approach intercepts 30-40% of queries with zero API tokens.
  • Streaming responses use Server-Sent Events (SSE) so tokens appear in the UI in real-time as the LLM generates them.
  • Caching reduces external API calls: weather (30 min), traffic (15 min), deals (2 hrs), geocoding (persistent), responses (5 min TTL).
  • Voice output uses browser SpeechSynthesis -- the response text never leaves the device for TTS processing.
